> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Architecture:** Keep the existing hub component structure and visual system. Update the destination registry as the single source of truth, reuse ViperCapture's production SVG mark, and update the hero's decorative mark without adding a second project card.

**Tech Stack:** React 19, TypeScript, Vite, Vitest, Playwright, GitHub Pages

- Use `https://capture.viperisuseful.cc` as the only hub destination for ViperCapture.
- Use the public name `ViperCapture` and the actual production SVG mark.
- Keep ViperCapture out of `systemDestinations` and make it the first `moreProjects` entry.
- Rename the section heading to `More works` without changing the approved page style.
