# ViperCapture Featured Swap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Feature ViperCapture beside QuickRunLab and move Turtle Cave to the first `More works` position without changing copy, assets, URLs, or layout.

**Architecture:** Keep `nightly-src/src/data/destinations.ts` as the single destination registry and swap the two complete destination objects between its exported arrays. Update registry, component, and browser assertions so placement is explicit, then regenerate the GitHub Pages root from the tested React/Vite source.

**Tech Stack:** React 19, TypeScript, Vite, Vitest, Testing Library, Playwright, GitHub Pages

## Global Constraints

- `featuredProjects` must be ordered `quickrunlab`, then `vipercapture`.
- `moreProjects` must begin with `turtle-cave`.
- Preserve every existing destination field, section heading, component structure, and CSS rule.
- Build only from `nightly-src`; do not edit generated root files directly.
- Do not commit, push, or publish without separate authorization.
